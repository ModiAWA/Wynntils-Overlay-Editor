# 高级使用

[返回使用指南](README.md) · [English](../../en-US/user/advanced-usage.md) · [文档总览](../../README.md)

本页面向需要自行运行、部署或调试工具的用户。普通用户直接使用托管网页即可，无需安装 Node.js。

## 本地打开

工具是无构建步骤的静态页面。最简单的方式是直接在浏览器打开项目根目录的 index.html。

如果浏览器限制了本地文件访问，或你希望模拟静态托管环境，可以使用任意静态服务器。例如：

```bash
python -m http.server 8000
```

然后访问 http://localhost:8000/。静态服务器只用于提供仓库文件，不需要后端服务。

## 自托管部署

部署时需要完整保留以下内容：

- index.html
- styles.css
- js/
- assets/

可以使用 GitHub Pages、Nginx、对象存储静态网站或其他静态托管服务。不要只上传 HTML；缺少生成的函数目录、翻译或字体位图会导致页面启动检查失败或预览不完整。

部署后如果浏览器仍显示旧模块，清理站点缓存并确认 HTML 中的脚本版本参数与实际文件一致。页面启动时会列出缺失的必需模块，便于定位不完整的发布包。

## AI 端点和 CORS

AI 请求从浏览器直接发送到你填写的 OpenAI-compatible Chat Completions 端点，因此服务端必须允许部署域名的 CORS 请求。建议：

1. 为编辑器部署单独的 API 代理或低权限 API Key。
2. 只允许必要的来源、方法和请求头。
3. 在代理端设置请求大小、速率和超时限制。
4. 不把 API Key 写入静态文件、URL、仓库或构建产物。

服务地址支持标准端点或兼容端点。页面会尝试从 /v1 或 /chat/completions 推导 /models；模型列表不可用时，手动填写模型名即可。

AI 对话最多执行有限次数的模型请求和本地函数检索。工具会拒绝 JSON 包裹的 Content、错误的反斜杠转义和未通过本地校验的代码块；应用建议前始终由用户确认。

## 离线和数据边界

除非你主动提交 AI 请求，浏览器不会访问远程 API。函数元数据、示例、翻译、校验、模拟和 Canvas 资源都来自仓库内文件。

草稿只保存在当前浏览器的本地存储中，并且只包含显式允许的 Info Box 配置。清理站点数据会删除草稿；它不会影响仓库文件或游戏内配置。

预览使用固定的示例状态。它不读取 Wynncraft 账号、服务器状态或游戏客户端实时数据，也不会把预览结果写回游戏。

## 排障

### 页面空白或提示模块缺失

确认部署包没有省略 js/ 下的控制器和生成文件。直接访问每个脚本的 URL，检查是否返回 404 或错误的 MIME 类型。然后硬刷新页面并查看控制台。

### 浏览器阻止 AI 请求

检查端点是否允许当前网页的 Origin、POST 方法和 Content-Type/授权请求头。也可以先在不使用 AI 的情况下验证编辑器和预览是否正常。

### 预览与游戏布局不同

确认 Content 没有被外部系统再次转义或包裹为 JSON 字符串。对于实时状态函数、字体资源包差异和客户端特有渲染效果，以游戏客户端为最终结果。

### 本地草稿无法载入

损坏或不兼容的草稿会被阻止恢复，以免覆盖当前内容。选择保留当前内容或明确替换；不要手动把对象值粘贴到 Content 字段。
