# 使用指南

[返回文档总览](../../README.md) · [English](../../en-US/user/README.md) · [高级使用](advanced-usage.md)

本指南面向通过托管网页使用 Wynntils Overlay Editor 的用户。工具当前重点支持 Wynntils Info Box 的 Content 编辑、预览和复制。

## 基本流程

1. 打开项目提供的托管网页。
2. 在“选择示例”中载入 FPS、坐标或“一般信息显示”示例，也可以从空白内容开始。
3. 在 Content 字段中编辑模板，并通过右侧函数目录搜索、插入函数表达式。
4. 根据预览和状态提示修复语法、类型或不支持模拟的函数。
5. 配置颜色模板、阴影、字体大小、Fit Text、背景和边框等 Info Box 选项。
6. 点击“复制 Content”，在游戏的 Wynntils → Overlay Management 中创建或编辑 Info Box。

复制的内容是游戏内表单需要的 Content 文本，不是完整的 Wynntils JSON。工具不会替你创建游戏内 overlay。

## 编辑 Content

模板表达式使用 Wynntils 的大括号语法，例如：

```text
{concat("FPS: ";fps)}
```

普通文字、函数、参数、字符串、数字和模板标点会在编辑器中分别高亮。高亮层只负责显示，实际输入仍由原生文本框处理，因此可以正常使用输入法、选择、撤销和键盘导航。

### 插入函数

- 在函数目录中搜索函数名、别名或中文描述。
- 点击结果会把带有示例参数的表达式插入 Content。
- 使用上下键移动焦点，按 Enter 插入，按 Escape 关闭搜索结果。
- 插入后通常会选中第一个可编辑参数，直接输入即可替换示例值。

函数目录来自 Wynntils 官方快照。函数的实时游戏状态不会被网页请求；无法离线确定的值会使用示例值或明确的占位提示。

### 颜色和格式

Minecraft/Wynntils 格式码、Color Template 和函数返回的颜色都会在预览中尽量还原。字面颜色使用八位十六进制 **&#RRGGBBAA**；状态提示会拦截不完整或非法的格式码。

## 预览和校验

预览区会区分以下情况：

- 空内容：清空旧画面。
- 语法或配置无效：保留并淡化最近一次有效预览，同时显示错误范围。
- 完整模拟：使用固定的示例游戏状态渲染。
- 部分模拟：保留结果，并列出使用占位符的函数。

预览不是游戏客户端截图。它主要用于检查布局、颜色、字体、格式码和文本长度；依赖实时游戏状态的函数不能被网页准确预测。

模拟结果和 Canvas 输入共享 4096 字符预算。超长结果会被截断并给出提示；用户提供的正则表达式不会在浏览器主线程中执行。

## 可选 AI 助手

AI 助手不是必需功能。不开启 AI 时，编辑、函数搜索、校验、预览和示例说明都保持离线。

使用 AI 时：

- 填写自己的 OpenAI-compatible Chat Completions 端点、模型名和 API Key。
- 端点必须允许浏览器跨域请求；兼容服务不一定提供 /models，此时可以手动填写模型名。
- API Key 只保留在当前页面的密码框中，不写入草稿、浏览器存储、URL、日志或下载文件。
- AI 不会自动覆盖 Content。只有明确的 Wynntils 代码块通过本地校验，并由你点击确认后才会应用。
- 不要把真实凭据、个人信息或生产数据发送给模型。

端点、请求边界、CORS 和本地运行方式见[高级使用](advanced-usage.md)。

## 草稿和撤销

普通 Info Box 配置会以版本化草稿保存在当前浏览器中，但 API Key、端点、模型和 AI 对话不会进入草稿。

未知版本或损坏的旧草稿不会被自动覆盖。多标签页同时编辑时，页面会提示你选择载入较新版本或保留当前内容。载入示例、应用 AI 方案和格式化等整段替换都可以撤销。

## 常见提示

- **出现函数占位符**：该函数依赖游戏状态或尚未纳入离线模拟，复制前请确认这是预期行为。
- **出现语法错误**：点击错误诊断可以聚焦对应范围，修复括号、引号、参数类型或格式码。
- **预览与游戏不同**：优先以游戏客户端为准；预览固定了示例状态，并不访问 Wynncraft 或 Wynntils 服务。
- **页面无法加载**：确认静态部署包含 index.html、styles.css、js/ 和 assets/，并查看浏览器控制台中的缺失模块提示。
